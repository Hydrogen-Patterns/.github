## Core Hydrogen Features

- **A Pattern Grid:** Place hits on a bar you can hear loop. The kit is samples the program ships or files you added and may use.
- **A Song of Patterns:** Chain patterns when one bar is not the whole piece.
- **Export Audio:** Write a WAV of what you hear when you need a file another program can open. Keep the song file so you can change a hit later.
- **Levels:** The mix is the volume of each drum. A hit you cannot hear may be muted or at zero, not missing from the kit.

---

## About Hydrogen

Hydrogen is a drum machine for patterns you program. You click hits, loop a bar, and export audio when the groove is the one you want. It does not extract drums from a commercial recording, and a beat you export is still your mix of the kit. If you add your own samples, they need to be samples you may use.

Start with one pattern and a few instruments. A full song of empty patterns is harder to debug than one bar that already sounds right. Save the song before you export. The WAV is a snapshot. The song file is what you edit when the snare is late.

Listen on the speakers you will actually use. A pattern that is only loud in headphones can be harsh on a desk speaker. Export, then open the WAV in a normal player and confirm the length.

## Getting Started with Hydrogen

Prerequisites: Working audio output, and a folder where the song and the WAV can live.

1. **New Song:** Save it before you build a long arrangement.
2. **One Pattern:** Place a kick and a snare and loop the bar.
3. **Save Again:** Then export a short WAV.
4. **Play the WAV:** Open it outside Hydrogen. Change the song, not the WAV, if a hit is wrong.

## Professional & Personal Use Cases

- **A Sketch:** A drum loop for a song you are writing.
- **A Practice Click with Tone:** A pattern you made, not a ripped track.
- **A File for Another Editor:** The WAV dropped into a project you own.
- **A Revision:** The Hydrogen song kept so the next version is a grid edit, not a guess.
